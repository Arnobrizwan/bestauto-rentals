# Design source

The brief for this build came from a Figma file supplied with the assessment:

<https://www.figma.com/design/YZVObhEegXBdtzHYA2u0fk/Task?node-id=0-1>

It contains two frames:

| Frame | Size | Built as |
|---|---|---|
| **Dashboard** | 1440 × 1234 | `/admin` — see [Admin dashboard](../../README.md#what-was-asked-and-where-it-is) |
| **Front end Wireframes** | 1440 × 5619 | `/` — the wireframe developed into a finished site |

`customer-front-end-wireframe.png` is a 1:1 export of the second frame, kept here so the built site can
be compared against what was asked for. Every section in it is present in the implementation: nav,
hero with the pick-up/drop-off search panel, how-it-works, the tabbed rental deals grid with
"Show more car", why-choose-us, the two promo panels, the testimonial carousel and the footer.

The dashboard frame is not exported here — the live `/admin` page is the artefact, and the design is
reachable at the Figma link above.

> The Figma file belongs to Digital Pylot and is reproduced here only as the reference for this
> submission.
